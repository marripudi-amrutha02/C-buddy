# C-Buddy - AI Study Buddy for CSE Students
Built with Switch + Telegram + Claude Code

Problem: CSE students waste hours searching notes, YouTube for doubts.

Solution: Telegram bot that:
- Answers DS, OS, CN, DBMS doubts with code
- Summarizes PDFs you forward
- Daily DSA question at 9 AM via Switch scheduler
- Schedules reminders

Why Switch is central:
Telegram -> Switch Server -> Claude Agent -> Switch -> Telegram
Without Switch, Telegram cannot trigger agents or schedule.
